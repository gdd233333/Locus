## 5. 动效 Motion

### 缓动曲线

```kotlin
// Spring — 用于可交互元素（按钮按下、卡片悬浮、导航切换）
val LocusSpring = CubicBezierEasing(0.34f, 1.56f, 0.64f, 1.0f)

// EaseOut — 用于入场动画（页面加载、卡片出现）
val LocusEaseOut = CubicBezierEasing(0.22f, 1.0f, 0.36f, 1.0f)
```

### 时长分级

| 场景 | 时长 | 曲线 |
|------|------|------|
| 按钮按下/释放 | 150ms | Spring |
| 卡片悬浮/选中 | 300~400ms | Spring |
| 页面入场 | 700~900ms | EaseOut |
| 波浪线绘制 | 2500ms | EaseOut |
| 进度条填充 | 1500ms | EaseOut |
| 导航圆点弹入 | 400ms | Spring |

### 「潮汐」节拍体系（装饰性循环动画的唯一标准）

> 所有无限循环的装饰动画，周期必须是基频 **4s** 的整数倍，相位同源。
> 每 32 秒全屏动画隐性同相一次——华丽感来自谐波秩序，而非各自为政。

```kotlin
object LocusRhythm {
    const val BASE = 4000
    const val BREATH = BASE      // 4s  脉动环 / 呼吸点 / 辉光 / SOS 扩散环
    const val GLOW = BASE * 2    // 8s  光晕 / 流动边框 / 角落光斑
    const val SHIMMER = BASE * 4 // 16s 卡片流光（湿琥珀漫射）
    const val AMBIENT = BASE * 8 // 32s 环境眩光 / 旋转弧光
}
```

**分层预算（每屏上限）：**

| 层 | 内容 | 每屏预算 |
|----|------|---------|
| 环境层 | AuroraBackground 动态眩光 + 边缘暗角 | 恰 1 个 |
| 容器层 | CardShimmer 卡片流光（相位错开） | ≤ 2 张卡 |
| 焦点层 | 脉动环组 / 计时器辉光等视觉主角 | 恰 1 个 |
| 反馈层 | bounceClick / 转场 / 入场交错 | 不受节拍约束 |

**减弱动态效果（无障碍）：** 跟随系统动画时长缩放设置（`LocalReduceMotion`）。
开启后装饰动画降级为静态帧（相位取 0、透明度取区间中值）；交互反馈保留；
SOS 保留静态低透明环（功能暗示不丢）。

### 特殊动效

**环境眩光（AuroraBackground，替代大理石纹理）**
- 4 团径向渐变光斑（琥珀×3 + 烟雾×1）沿利萨茹轨迹漂移，周期 32s
- 边缘压暗暗角（中心透明 → 边缘 InkBackground 60%），让中央光斑显形
- 透明度上限锁死 0.30，不得影响可读性

**卡片流光（CardShimmer）**
- 湿琥珀漫射：大半径软光斑水平缓慢漂移 + 角落呼吸光斑，周期 16s
- 禁止窄条扫光带（廉价感）

**脉动环（Streak 外圈）**
- 三个同心环，`scale 0.92 → 1.08`，`opacity 0.55 → 0.12`
- 周期 4s，交错延迟 0 / 700 / 1400ms

**旋转弧光（OrbitArcs）**
- 三条琥珀/烟雾圆弧沿圆周反向旋转，周期 32s

**SOS 按钮扩散环（常开）**
- 双层光环 `scale 1.0 → 1.4` + `opacity 0.45 → 0`，周期 4s，双环相位差半周期
- 投影呼吸 10~20dp，周期 4s

**正在记录卡片**
- 流动虚线边框：dashPathEffect 相位推进，虚线沿边框爬行，周期 8s
- 计时器文字辉光：`Shadow(Amber, blurRadius 32)` 透明度呼吸，周期 4s

### 入场动画模式

```kotlin
// 标准入场：自底向上 24dp 淡入
val fadeUpEnter = fadeIn(
    animationSpec = tween(900, easing = LocusEaseOut)
) + slideInVertically(
    initialOffsetY = { 24.dp.roundToPx() },
    animationSpec = tween(900, easing = LocusEaseOut)
)

// 交错延迟：同一屏内多个元素依次入场
val staggerDelays = listOf(0, 100, 250, 400, 550) // ms
```

### 特殊动效

**脉动环（Streak 外圈）**
- 两个同心圆，半径 220dp / 260dp
- `scale: 1.0 → 1.06 → 1.0`，`opacity: 0.6 → 0.2 → 0.6`
- 周期 4s，第二个环延迟 1s

**SOS 按钮呼吸**
- `boxShadow: 0 8dp 32dp rgba(217,165,102,0.35) → 0 8dp 40dp rgba(217,165,102,0.55)`
- 周期 3s

**正在记录卡片边框流动**
- 渐变边框 `opacity: 0.4 → 0.15 → 0.4`
- 周期 4s

**正在记录状态圆点**
- `opacity: 1.0 → 0.6 → 1.0` + 外圈扩散 `0dp → 6dp → 0dp`
- 周期 2s

## 8. 氛围质感：动态眩光（已替代大理石纹理）

> **2026-09 决策更正**：「大理石纹」的真实意图是**动态眩光特效**，不是静态贴图。
> 静态大理石 PNG 已全部删除，不要再生成或使用。

实现位于 `designsystem/component/Aurora.kt`：

- **AuroraBackground**：屏幕级环境眩光（4 团漂移光斑 + 边缘暗角），每屏恰 1 个
- **CardShimmer**：卡片级湿琥珀漫射流光，每屏 ≤ 2 张卡
- 周期和分层预算遵循 §5 的潮汐节拍体系
- 系统开启减弱动态效果时全部降级为静态帧

## 9. 全局布局规范

- 手机屏幕基准：390dp × 844dp（iPhone 14 Pro 逻辑尺寸，Android 适配用 `fillMaxSize`）
- 底部导航在所有主屏幕常驻
- SOS 按钮仅在戒断中心屏幕显示，悬浮于底部导航上方 16dp（不再大幅上浮压内容）
- 所有可滚动内容区域底部 padding ≥ 110dp（避免被 SOS 按钮和导航遮挡）
