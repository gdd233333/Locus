## 1. 配色 Color Tokens

| Token 名 | Hex | Compose 语义 | 用途 |
|----------|-----|-------------|------|
| `InkBackground` | `#12100F` | `background` | 页面底色，近黑暖墨，夜间不刺眼 |
| `InkSurface` | `#1C1A18` | `surface` | 卡片、底部导航 |
| `InkSurface2` | `#242120` | `surfaceVariant` | 次级卡片、进度条底、tag 背景 |
| `Amber` | `#D9A566` | `primary` | 主强调色：streak 数字、激活态、SOS 按钮、进度条 |
| `AmberDim` | `#D9A566` @ 14% | `primaryContainer` | 琥珀色淡化底：图标背景、chip 背景、标签底色 |
| `Smoke` | `#E8E3DA` | `onBackground` / `onSurface` | 标题、正文、主要文字 |
| `Stone` | `#8A857C` | `onSurfaceVariant` | 辅助文字、次要信息、未激活导航 |
| `StoneDark` | `#4A463F` | `outline` | 分割线、虚线框、未激活边框 |
| `Line` | `#E8E3DA` @ 8% | `outlineVariant` | 卡片边框、列表分割线 |

### 透明度变体

```
AmberDim    = Amber.copy(alpha = 0.14f)
Line        = Smoke.copy(alpha = 0.08f)
```

## 5. 动效 Motion

### 缓动曲线

```kotlin
// Spring — 用于可交互元素（按钮按下、卡片悬浮、导航切换）
val LocusSpring = CubicBezierEasing(0.34f, 1.56f, 0.64f, 1.0f)

// EaseOut — 用于入场动画（页面加载、卡片出现）
val LocusEaseOut = CubicBezierEasing(0.22f, 1.0f, 0.36f, 1.0f)
```

### 时长分级

| 场景 | 时长 | 曲线 |
|------|------|------|
| 按钮按下/释放 | 150ms | Spring |
| 卡片悬浮/选中 | 300~400ms | Spring |
| 页面入场 | 700~900ms | EaseOut |
| 波浪线绘制 | 2500ms | EaseOut |
| 进度条填充 | 1500ms | EaseOut |
| 呼吸/脉动循环 | 2000~4000ms | EaseInOut |
| 边框流动循环 | 4000ms | EaseInOut |
| 导航圆点弹入 | 400ms | Spring |

### 入场动画模式

```kotlin
// 标准入场：自底向上 24dp 淡入
val fadeUpEnter = fadeIn(
    animationSpec = tween(900, easing = LocusEaseOut)
) + slideInVertically(
    initialOffsetY = { 24.dp.roundToPx() },
    animationSpec = tween(900, easing = LocusEaseOut)
)

// 交错延迟：同一屏内多个元素依次入场
val staggerDelays = listOf(0, 100, 250, 400, 550) // ms
```

### 特殊动效

**脉动环（Streak 外圈）**
- 两个同心圆，半径 220dp / 260dp
- `scale: 1.0 → 1.06 → 1.0`，`opacity: 0.6 → 0.2 → 0.6`
- 周期 4s，第二个环延迟 1s

**SOS 按钮呼吸**
- `boxShadow: 0 8dp 32dp rgba(217,165,102,0.35) → 0 8dp 40dp rgba(217,165,102,0.55)`
- 周期 3s

**正在记录卡片边框流动**
- 渐变边框 `opacity: 0.4 → 0.15 → 0.4`
- 周期 4s

**正在记录状态圆点**
- `opacity: 1.0 → 0.6 → 1.0` + 外圈扩散 `0dp → 6dp → 0dp`
- 周期 2s

| 场景 | 阴影 |
|------|------|

| 激活日期药丸 | `0 4dp 16dp rgba(217,165,102,0.3)` |
| 普通卡片 | 无阴影，用 `1dp Line` 边框 |

## 8. 大理石纹理实现策略

HTML 版用 SVG `feTurbulence` 生成。Compose 中没有直接等价物，推荐以下方案（按优先级）：

### 方案 A：预渲染 Bitmap（推荐 MVP 用）

1. 用 Python/Node 脚本离线生成 3~5 张大理石纹理 PNG（不同 seed、不同密度）
2. 放入 `res/drawable-nodpi/`
3. Compose 中用 `Image` + `alpha` + `BlendMode` 叠加

### 方案 B：Compose 自定义 Drawing

用 `Canvas` + `Path` + `Brush.linearGradient` 模拟流体曲线，配合 `NoiseFilter`（如果有）或多层半透明波形叠加。

### 方案 C：Runtime Shader（Android 13+）

用 `RuntimeShader` 写 GLSL 实现分形噪声，效果最接近 SVG turbulence，但有 API 级别限制。

**MVP 阶段建议用方案 A**，纹理文件在 Stage 2 由牛马生成。

## 9. 全局布局规范

- 手机屏幕基准：390dp × 844dp（iPhone 14 Pro 逻辑尺寸，Android 适配用 `fillMaxSize`）
- 底部导航在所有主屏幕常驻
- SOS 按钮仅在戒断中心屏幕显示，悬浮于内容之上、导航之下
- 所有可滚动内容区域底部 padding ≥ 110dp（避免被 SOS 按钮和导航遮挡）
