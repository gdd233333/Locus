## 项目定位

Locus 是一款 Android 自律应用，帮助用户戒除色情/手淫、记录时间去向、用替代活动填充空虚时间。核心理念：**不预设计划、不强制阻断，只记录、只陪伴、事后复盘**。

项目名 Locus 来自心理学概念 "locus of control"（控制点）——内控型的人相信自己能掌控人生。

## MVP 三模块

| 模块 | 核心功能 | 对应 Tab |
|------|---------|---------|
| **戒断中心** | Streak 打卡、冲动记录与急救、冲浪曲线可视化 | 守护 |
| **灵感行动库** | 按时长/场景筛选的替代活动推荐，摇一摇换一批 | 灵感 |
| **时间记录** | 手动开始/结束记录时间段，事后复盘 | 记录 |

第四个 Tab「复盘」MVP 阶段为占位页，显示"敬请期待"。

## 技术架构

```
app/
├── designsystem/          # 设计系统模块（独立 module，未来可抽成独立 repo）
│   ├── theme/             # 颜色、字体、间距、圆角、动效 tokens
│   ├── component/         # 自定义组件（BottomNav、SosButton、卡片等）
│   └── texture/           # 大理石纹理资源
├── core/
│   ├── data/              # Repository 实现 + Room 数据库
│   ├── model/             # 数据模型（StreakRecord、UrgeEvent、TimeLog 等）
│   └── common/            # 工具类、扩展函数
├── feature/
│   ├── sober/             # 戒断中心（Screen + ViewModel + Sheet）
│   ├── inspire/           # 灵感行动库
│   ├── timelog/           # 时间记录
│   └── review/            # 复盘（占位）
└── MainActivity.kt        # 单 Activity + Compose Navigation
```

**关键原则：**
- 每个屏幕先定义 `UiState` 数据类 + 假 Repository，界面和动画全部用假数据跑通
- UI 的状态契约就是业务层的接口规范（前端约束业务）
- `designsystem` 不依赖任何 feature 模块，可独立编译

## 牛马使用指南

### 怎么用 Stage 文档

1. 打开对应 Stage 的 markdown 文件
2. 找到「提示词」部分（用代码围栏 ` ``` ` 包裹的大段文字）
3. **整段复制**，粘贴给你的牛马 Agent
4. 等牛马执行完毕
5. 按照「验证清单」逐项检查产出

### 牛马执行失败怎么办

- **编译报错**：把错误信息原样贴回给牛马，让它修复
- **效果不对**：对比设计稿 HTML 文件（`design/版本A - 墨石（深色极简）.html`），截图给牛马看差异
- **牛马问问题**：如果牛马问到文档里没有的信息，回来查 `01-设计系统-墨石.md` 或 `02-信息架构.md`

### 提示词使用注意

- 提示词是**自包含**的，牛马不需要读其他文件
- 提示词里包含完整代码，牛马只需要"创建文件 → 粘贴 → 验证编译"
- 每个提示词的工作量控制在 30 分钟以内
- 如果牛马说"需要更多上下文"，把对应的 `01` 或 `02` 文档也贴给它
