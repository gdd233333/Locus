### 二、每个 Stage 文档的统一模板

```
## 前置条件
（列出此阶段开始前必须完成的事项，如"Stage 1 已完成，项目能编译通过"）

## 目标
（这个阶段结束时，项目应该达到什么状态）

## 提示词（直接复制给牛马 Agent）
（完整的、自包含的提示词块，用代码围栏包裹。牛马拿到后不需要任何额外上下文就能执行。
  包含：要做什么、改哪些文件、写什么代码、怎么验证、遇到错误怎么办）
```

### 三、提示词写作策略（针对通用廉价 LLM Agent）

- **自包含**：每个提示词块包含完整的上下文——项目结构、已有代码的关键片段、明确的文件路径和要写的代码内容。牛马不需要读其他文档。
- **代码直给**：对于设计 tokens、数据模型等确定性内容，提示词里直接包含完整代码，牛马只需要"创建文件 → 粘贴 → 验证编译"。
- **验证步骤明确**：每个提示词末尾附带验证命令（如 `./gradlew assembleDebug`）和预期输出。
- **错误处理指引**：告诉牛马"如果编译失败，把错误信息原样贴回来"。
- **单次任务量控制**：每个提示词的工作量控制在 30 分钟以内，避免牛马迷失。

### 四、各文件内容要点

**00-项目总览.md**
- 项目名 Locus（已锁定），包名 `com.locus.app`
- 技术栈：Kotlin + Jetpack Compose（不用 Material3）+ Room + DataStore + Glance
- 视觉方向：版本A「墨石」深色极简（已锁定）
- 三模块：戒断中心 / 灵感行动库 / 时间记录（手动记录，非计划）
- 约束策略：软提醒 + 数据复盘，不要硬阻断
- 五阶段路线图及各阶段产出物
- 牛马使用指南：如何复制提示词、如何验证结果、如何回报问题

**01-设计系统-墨石.md**
- 从版本A HTML 逐值提取：6 色色板（hex）、字体栈（DM Serif Display / Noto Sans SC / Space Grotesk）、字阶（Display 34 / Heading 24 / Body 15 / Mono 14）、间距 scale、圆角 scale（16/20/24/28/999）、动效曲线（spring / ease-out）、动效时长（0.3-1s 分级）
- 组件清单：每个组件的状态（default/hover/active/disabled）+ 对应的 Compose 语义
- 大理石纹理的 Compose 实现策略（Brush + NoiseFilter 或预渲染 bitmap）

**02-信息架构.md**
- 数据模型：StreakRecord / UrgeEvent / Activity / ActivityCategory / TimeLog / TimeLogStatus
- 屏幕清单：守护（戒断中心）/ 灵感 / 记录 / 复盘（占位）
- 导航：底部四 tab + 各屏幕内部导航
- 交互流程：打卡 / 冲动急救 / 开始-结束时间记录 / 摇一摇换活动
- 每屏的 UiState 数据类定义（前端约束业务的契约）

**03~07 Stage 文档**
- 各自包含完整的可复制提示词，内容如上模板所述
